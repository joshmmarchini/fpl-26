## Development setup

This project uses a virtual environment and [pip-tools](https://github.com/jazzband/pip-tools) to manage dependencies.

- `requirements.in` – the packages we directly use (edit this)
- `requirements.txt` – the full pinned list, generated by pip-tools (don't edit by hand)

### First-time setup

```bash
python -m venv .venv
source .venv\Scripts\activate # Windows
pip install pip-tools
pip-sync requirements.txt
```

### Adding or removing a package

1. Add or remove the package name in `requirements.in`
2. Regenerate the lock file and update your environment:

   ```bash
   pip-compile requirements.in
   pip-sync requirements.txt
   ```

3. Commit both `requirements.in` and `requirements.txt`

> Don't `pip install` packages directly. `pip-sync` removes anything not listed in `requirements.txt`.

### Upgrading packages

```bash
pip-compile --upgrade requirements.in             # all packages
pip-compile --upgrade-package <name> requirements.in  # one package
pip-sync requirements.txt
```

## Backlog

### Try to predict xg of a player for a given match
- Add in trailing 1 gw, 3, 5 gw columns 
- Calculate player's expected minutes using exponentially weighted rolling average
- Create a 60 minute proxy for if a player started
- Calculate a baseline rolling average of xg
    = player's aveage xG per 90 over last 3 matches * expected minutes


## Notes
- Predicting xg for a gw is non-negative, heavily right-skewed. So it is noisy.
